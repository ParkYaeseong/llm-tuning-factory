# Windows 0.2.3 실제 GPU 검증 · 2026-10-15

Windows 설치 앱에서 실제 H100 80GB와 공용 MLflow를 연결해 합성 데이터 학습과 복구를 검증했습니다.
이는 내부 검토용 배포의 실행 검증이며, 실제 업무 데이터의 성능 검증은 아닙니다.
원본 기관 데이터는 전송하지 않았습니다.

어댑터는 각각 96개 유한 텐서와 196,608개 0이 아닌 LoRA B 값을 확인했습니다.

## 검증 중 수정한 문제

- CUDA가 있어도 C 컴파일러가 없는 최소 이미지에서는 Triton 초기화가 실패했습니다.
  준비·연결 검사에서 먼저 차단하고 관리자가 컴파일러를 준비하도록 안내합니다.
- GPU가 사용 중일 때 실행 결과가 없으면 완료라고 안내하던 화면을 대기 안내로 수정했습니다.
- LLaMA-Factory 0.9.5의 양자화 식별자는 `bnb`입니다. 이전 `bitsandbytes` 값이 무시되어
  BF16으로 학습되는 문제를 실제 로더 검사로 발견하고 학습·생성 양쪽을 수정했습니다.
  이제 양자화 확인 로그가 없으면 성공으로 인정하지 않습니다.
  이전 실행 `42397455771d4c2ca8e6066ea6fcba33`은 **검증 탈락·MLflow FAILED**로 정정했습니다.
  그 실행의 완료 상태나 설정의 4비트 표시는 QLoRA 성공 증거가 아닙니다.

최종 QLoRA 및 PC 연결 복구는 소스 SHA256
`c5b040822868981c064ebb183c9a741424ea03d096f11b45c9ae1c361a2228ee`에서 확인했습니다.
이전 LoRA·체크포인트·대기열 시험은
`8f91704981fadb47694fbb0c8fc4a1683427bbbc4c70cade72936285083f9298`에서 수행했습니다.
최종 수정 이후 모든 이전 시나리오를 다시 실행했다는 의미는 아닙니다.

## 배포·검사·자원 정리

설치 파일은 `LLM Tuning Factory_0.2.3_x64-setup.exe`, 44,917,847바이트입니다.
SHA256: `35c9995db4d720506a3814f9e142ebe94ef776e0de0aae447d486fd56a464af5`.
실제 설치 앱의 화면 버전 0.2.3과 실행 엔진 바이트 일치를 확인했습니다.
NSIS는 네이티브 실행 파일의 bundle type 표시 3바이트(UNK→NSS)를 변경합니다.
테스트 인증값은 삭제하고 이전 일반 설정을 복원했습니다. 전체 산출물은 검증 PC에 보존했습니다.

Python 3.12 잠금 설치, pytest **78 passed / 1 skipped**, Ruff를 통과했습니다.
스킵은 기본 비활성 GPU pytest이며 이 문서의 실제 GPU 시험은 별도입니다.
UI **10개**, TypeScript/Vite, Rust allowlist 검사와 설치 패키지 검증을 통과했습니다.
최종 UI 코드 `1222d62`의 GitHub CPU 검사 `38667226882`와 Windows 패키징
`38667226909`도 성공했습니다.

기존 H200은 호스트 GPU 부족으로 시작할 수 없어 EXITED 상태를 유지했습니다.
사용자 승인으로 생성한 임시 H100만 사용했으며, **EXITED 확인 후 삭제하고 GET 404를 확인**했습니다.
기존 Pod와 Network Volume은 보존했습니다. 최대 추산 GPU 사용은 82.36분 / **$5.48**로,
승인 한도 90분 / $5.99 이내입니다. 저장 비용은 별도입니다.

자세한 값은 [비밀정보를 제외한 검증 영수증](acceptance/2026-10-15-desktop-gpu.json)에 있습니다.
설치 파일은 [비공개 GitHub 릴리스](https://github.com/ParkYaeseong/llm-tuning-factory/releases/tag/v0.2.3)에서 제공합니다.

## 현재 제공 범위와 남은 작업

학습 설정·실행 관리·공용 기록 비교는 제공하지만 LLaMA-Factory 전체 UI를 대체하지 않습니다.
정해진 Qwen/Llama 모델 목록과 **SFT LoRA·QLoRA**가 범위입니다.
전체 모델별 학습 방식 자동 호환표, 전체 파인튜닝·DPO·PPO·RM은 지원하지 않습니다.
실제 GPU 시험 모델도 위 Qwen 0.5B 하나이며 다른 목록 모델까지 검증한 것은 아닙니다.

학습 데이터는 **로컬 Alpaca/ShareGPT JSON·JSONL**입니다.
**S3 등 외부 스토리지 데이터 직접 연결·브라우징·스트리밍은 아직 없습니다.**
MLflow 서버가 내부적으로 사용하는 산출물 저장소는 학습 데이터 연결 기능과 별개입니다.
대량 데이터 스트리밍, 다중 PC 중앙 스케줄링, 서빙도 제공하지 않습니다.

새 PC에서의 설치, 코드 서명, 접근 제한 모델 인증, 학습 어댑터 Model Registry 등록,
독립 GPU 이미지 빌드와 수치 재현성은 이번 인정 범위에 포함하지 않았습니다.
이 단계에서는 내부 사용자가 예제 데이터로 검토하고, 실제 업무 품질은 별도 평가해야 합니다.
