# Windows v0.6.1 — English / 한국어

Windows x64 **prerelease** of LLM Tuning Factory, with a bundled Python control engine.

## What's new

- **ENG / KOR** selector at the top right. Language changes immediately and is remembered on this PC; the initial default remains Korean.
- Translated navigation, forms, workflow guidance, approvals and tutorial, backed by 1,697 English messages.
- Language changes preserve in-memory drafts and reviewed plans without saving credentials or submitting a job. User data, project names, model IDs and raw logs retain their original content.
- English and Korean READMEs with four matching UI walkthrough GIFs per language.
- This installer also includes the 0.5/0.6 work since the previous public 0.4.0 installer: modern-model/runtime compatibility checks and the latest GPU preflight and model-operation fixes. Historical GPU evidence remains separate from this release's offline checks.

## Download and update

Download **LLM.Tuning.Factory_0.6.1_x64-setup.exe** and its `.sha256` file from the assets below.

1. In the existing app, request **Stop controller** and wait until it is stopped, then close the app before updating. Closing its window alone does not stop the controller.
2. Run the installer. Keep application data; do not select the uninstall option that deletes projects, datasets and history.
3. Open the workspace and select **ENG** or **KOR** at the top right. Try the tutorial or a dry-run plan first.

The installer is **unsigned**. Check its SHA-256:

```powershell
(Get-FileHash -Algorithm SHA256 .\LLM.Tuning.Factory_0.6.1_x64-setup.exe).Hash.ToLower()
```

Expected: `d3bd47ca31c40bb05fd1ff04d6dc8716ff4dc09edddf5aa2348fb7a26ca43b06`

## Verification and scope

- Release source: `9f0c7103752fef192da80074aaf9d5b815585f6a`.
- Local Python: **2,245 passed, 2 skipped**; Ruff passed.
- Frontend: **291 tests passed**; TypeScript/Vite production build passed.
- Rust: **54 tests passed**.
- Frozen Python engine: all five offline acceptance groups passed, including immutable dry-run plans, workflow/controller simulation, clean controller shutdown and worker-wheel/source matching.
- Native Windows WebView: English/Korean navigation, draft preservation and language persistence after reload passed in a separate test WebView profile. The test did not save connections or submit training.
- See **verification-0.6.1.json** for artifact hashes and acceptance results.

Hosted Ubuntu CPU CI passed for the release commit. Hosted Windows CPU CI was still running when these notes were prepared; the local Windows Python, frontend, Rust and frozen-engine checks above passed. [Hosted CI](https://github.com/ParkYaeseong/llm-tuning-factory/actions/runs/42183843307).

No new paid GPU run, dataset transfer or external service acceptance was performed for this release. The NSIS installer was built; installation/upgrade itself was not repeated in this session. Existing historical GPU tests use synthetic data and do not establish task-model quality. Original backend diagnostics may remain beside translated explanations, and OS dialogs follow the OS language.

## 한국어 안내

오른쪽 위 **ENG / KOR**에서 언어를 바꾸고 다음 실행에도 선택을 유지할 수 있습니다. 작성 중인 값과 검토한 실행 계획은 보존하며, 언어 변경으로 인증값을 저장하거나 학습을 제출하지 않습니다.

기존 앱을 업데이트하기 전에는 **컨트롤러 정지 → 정지 요청** 후 실제 정지까지 기다리고 창을 닫으세요. 프로젝트·데이터·기록을 유지하고, 제거 과정의 ‘애플리케이션 데이터 삭제’는 선택하지 마세요. 설치 파일은 코드 서명하지 않았으므로 함께 제공한 SHA-256을 확인하세요.

이번 릴리스는 실제 GPU 학습을 새로 검증한 버전이 아닙니다. GPU를 사용하거나 데이터를 전송하려면 별도의 실행·전송 승인이 필요합니다. 사용자 Pod는 앱이 임의로 중지하거나 삭제하지 않습니다.
